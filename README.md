# ripplow-e2e-test

Throwaway repository for the Ripplow end-to-end test: the AI team works here through the console. Deleted after the test.

## Usage

Import the functions from `greet.js` (ES modules):

```js
import { greet, farewell } from './greet.js';

greet('Ripplow');    // 'Hello, Ripplow!'
farewell('Ripplow'); // 'Goodbye, Ripplow!'
```
